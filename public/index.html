CONNECT THE RUNNER

Flowbench runs your Python on your own computer through a small local program. Do this once:

  1. Download runner.py and put it anywhere (for example your Desktop).
  2. Install its two helpers (once):
    pip install websockets pywinpty
    pywinpty gives full terminals on Windows. On macOS / Linux just pip install websockets.
  3. Start it, pointing at the folder with your code:
    python runner.py --root "C:\Users\zicha\OneDrive\Desktop" --examples
    --examples adds a small demo folder. Your browser opens Flowbench at http://127.0.0.1:8765, already connected. Use that address from then on.
Connect manually

Why a local address? Browsers increasingly block public websites from talking to programs on your computer, so the runner serves this same app locally. The runner only listens on this computer (127.0.0.1), needs the secret token, and only reads the folders you pass with --root. If Chrome asks to allow access to devices on your local network, allow it.
