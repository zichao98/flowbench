CONNECT THE RUNNER

Flowbench runs your Python on your own computer through a small local program. Install it once, with one line:

  1. Windows: open PowerShell and paste
    irm https://flowbench.zichaoleng55.workers.dev/install.ps1 | iex
    macOS / Linux: open Terminal and paste
    curl -fsSL https://flowbench.zichaoleng55.workers.dev/install.sh | bash
    Needs Python 3.9+. Nothing is installed into your own Python; the runner gets a private environment.
  2. From then on just double-click Flowbench on your Desktop (or type flowbench in any terminal). It opens at http://127.0.0.1:8765, already connected.
  3. Handy commands:
    flowbench add .          # show the current folder's code in the library
flowbench python C:\path\to\env\python.exe   # run your code with a specific env
flowbench examples       # add a small demo folder
flowbench stop · status · update · help
Manual setup (without the installer)

Download runner.py, run pip install websockets pywinpty, then python runner.py --root "C:\path\to\code".

Connect manually

Why a local address? Browsers increasingly block public websites from talking to programs on your computer, so the runner serves this same app locally. The runner only listens on this computer (127.0.0.1), needs the secret token, and only reads the folders you added. If Chrome asks to allow access to devices on your local network, allow it.
